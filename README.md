# Virtualna galerija umjetnosti
## O projektu
Virtualna galerija umjetnosti je web stranica koja prikazuje remek-djela svjetske umjetnosti kroz različite umjetničke pravce. Cilj web stranice je omogućiti korisnicima da na jednostavan način istraže umjetnost, uz pregled vizualnog sadržaja, opisa i dodatnih informacija o najpoznatijim djelima.
