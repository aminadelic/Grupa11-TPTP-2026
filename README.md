# Grupa11-TPTP-2026
Naziv projekta: Virtualna galerija umjetnosti

Tema: Virtualna galerija umjetnosti(Remek-djela svjetske umjetnosti)

Članovi grupe: Amina Arifagić (aminaa63), Amina Bulić (aminabulic), Amina Delić (aminadelic)

Opis: Virtualna galerija umjetnosti je web stranica koja prikazuje remek-djela svjetske umjetnosti kroz različite umjetničke pravce, uz osnovne informacije o djelima. Cilj web stranice je omogućiti korisnicima da na jednostavan način istraže umjetnost, uz pregled vizuelnog sadržaja, opisa i dodatnih informacija o najpoznatijim djelima.
